GITHUB PAGES KURULUMU
1. Bu klasördeki index.html, config.js ve PNG dosyasını GitHub repository'sinin yayınlanacak köküne yükleyin.
2. GitHub > Settings > Pages > Build and deployment bölümünde Deploy from a branch seçin.
3. Branch olarak main, folder olarak / (root) seçin ve Save deyin.
4. Birkaç dakika sonra Pages adresi oluşur.
5. 404 alırsanız repository'nin Pages ayarındaki branch/folder seçimini kontrol edin.
